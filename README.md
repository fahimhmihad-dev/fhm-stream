# FHM Stream — Watch Live TV

A live TV streaming website that aggregates publicly available stream links into one simple, easy-to-use viewing experience.

🔗 **Live Website:** https://tv.getyourservicebd.store

## About the Project

FHM Stream was built to make watching live TV channels online simple and accessible from any device. The site collects publicly available stream links and presents them in a clean interface.

## Features

- Live TV channel streaming in the browser
- Simple, user-friendly interface
- Works across devices
- Deployed live on a custom subdomain

## Tech Stack

- HTML5, CSS3
- Built with AI-assisted development tools (Lovable / Antigravity workflow)
- Deployed on a custom domain

## What I Learned

- Building and deploying a complete, live web product end-to-end
- Working with streaming links and web playback
- Domain, subdomain, and deployment configuration
